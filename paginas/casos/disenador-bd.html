Caso 04

Diseñador visual de bases de datos

Herramienta creativa para modelado · En desarrollo

El modelo relacional suele vivir en un diagrama estático o en un script. Esta herramienta busca diseñarlo, verlo y entenderlo como un espacio.

JavaScript SQL Canvas

Por qué existe

Diseño bases todos los días. Las herramientas que lo hacen “bien” o son pesadas, o son una foto. Quiero un lienzo donde las tablas, las relaciones y el SQL se sientan parte del mismo gesto: mover, conectar, leer.

Qué estoy construyendo

  • Un espacio en canvas para colocar entidades y relaciones.
  • Una lectura del esquema que no sea solo el dibujo: que se pueda volver SQL.
  • Una interfaz que se sienta diseñada, no un editor de cajas genérico.

Estado

En desarrollo. Aún no hay una versión pública para enlazar. Cuando el lienzo se pueda mostrar sin pedir disculpas, este caso tendrá capturas y, si cabe, una demo.
